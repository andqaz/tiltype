# TilType AI

Отдельный экспериментальный плагин для текстового редактора ONLYOFFICE
10.0+. После пробела он вычисляет следующее слово и предлагает вставить его
клавишей **Tab**. Модели русского, казахского и английского входят в пакет.
Вычисления выполняет JavaScript на процессоре. Интернет, видеокарта и
отдельное приложение для запуска модели не нужны.

Установите `dist/tiltype-ai.plugin` через менеджер плагинов и включите
**TilType AI** в списке фоновых плагинов. При ручном сравнении с обычным
TilType оставляйте включённым один прогноз следующего слова, чтобы два списка
у курсора не перекрывали друг друга.

После принятия подсказки по **Tab** плагин сразу перечитывает предложение.
Можно принять следующее продолжение ещё одним нажатием **Tab**. Клавиша
**Esc** скрывает список.

## TilType AI Phrases

Отдельный пакет `dist/tiltype-ai-phrases.plugin` предлагает до трёх вариантов
на русском, казахском и английском. Первый вариант выбран сразу. Стрелки
**↑** и **↓** меняют выбор, **Tab** вставляет выбранное слово или фразу.
Модель использует до 24 слов и не более 600 символов текущего предложения.
Запятые и двоеточия сохраняют предшествующий контекст внутри предложения.
Фразы из двух слов появляются при согласии нейронной модели с обучающим
корпусом. Если фраза встретилась не менее восьми раз и занимает не менее
72% продолжений этого контекста, достаточно подтверждения корпуса.
Устойчивое однословное продолжение тоже может подняться на первое место.
Слабые нейронные варианты скрываются.

В моделях по 16 384 слова. Дополнительный этап использовал по 1,6 млн позиций
на язык из Tatoeba, Leipzig, а для казахского ещё и KazNERD. Корпусный ресурс
содержит 18 955 двухсловных продолжений и 28 821 однословное продолжение
для контекстов из двух или трёх слов. Для 4 451 двухсловного продолжения
зафиксировано более сильное корпусное подтверждение.

На 3 000 отложенных позициях каждого языка, включая 1 500 длинных контекстов,

Сборка нового фразового пакета из весов текущего однословного AI:

```powershell
$models = ".cache/tiltype-phrases-models"
$baseline = "dist/tiltype-ai.plugin"
foreach ($language in "ru", "kk", "en") {
    python tiltype-ai/tools/train_sentences.py $language $baseline $models
    python tiltype-ai/tools/build_phrase_evidence.py $language $models
}
python tiltype-ai/tools/build.py --phrases --models $models
python tiltype-ai/tools/benchmark_sentences.py --candidate dist/tiltype-ai-phrases.plugin --output tiltype-ai/sentence-benchmark-results.json
```

Для сравнения с прежней фразовой сборкой передайте её в
`--previous-phrases`. Параметр `--partition development` использует выборку
для подбора и оставляет контрольную выборку для итоговой проверки.

### Дополнительные диалоги и расшифровки

Источники, лицензии и зафиксированные выпуски перечислены в
[DIALOGUE-CORPORA.md](DIALOGUE-CORPORA.md). Для импорта нужны PyArrow,
fsspec и aiohttp. Сохраните ZIP выпуска Taskmaster как `taskmaster.zip`,
`2023-04-12_oasst_ready.messages.jsonl.gz` как `oasst1-ready.jsonl.gz`
и обучающий Parquet Matreshka как `matreshka-train.parquet` в одном каталоге.
Для казахского языка скрипт читает только текстовый столбец KSC2 через HTTP.

```powershell
$corpora = '.cache/dialogue-corpora'
$candidateModels = '.cache/dialogue-candidate-models'
$previous = '.cache/tiltype-ai-phrases-previous.plugin'
foreach ($lang in 'en', 'ru', 'kk') {
    python tiltype-ai/tools/import_dialogues.py $lang $corpora
    python tiltype-ai/tools/train_sentences.py $lang $previous $candidateModels --dialogues $corpora
}
```

Для сравнения только весов скопируйте прежние `models/*-phrases.json`
из `$previous` в `$candidateModels`. Соберите отдельный пакет через
`build.py --phrases --models $candidateModels --output <путь-к-кандидату> --training-notice tiltype-ai/DIALOGUE-CORPORA.md`
и сравните его с `$previous` через `benchmark_sentences.py --previous-phrases`.
Объём после очистки сохраняется в `*-import.json`.

Для фразового режима `build_context_ranking.py <язык> <каталог-диалогов>
<файл-модели-phrases.json>` добавляет компактные распределения для
контекстов из одного, двух или трёх слов. Движок смешивает оценки
нейросети с самым длинным подходящим распределением. Уже подтверждённые
корпусом фразы сохраняют приоритет.

Экспериментальный `build_phrase_extensions.py` строит для русского и казахского отдельное
подтверждение второго слова по контексту и выбранному первому слову.
Окончание предложения учитывается в статистике как позиция без
продолжения. При показе JavaScript дописывает второе слово только после
того, как сеть уверенно выбрала первое и подтвердила продолжение
повторным прогнозом. Короткий контекст требует большей уверенности.
Кандидат дал 5 из 9 точных фраз на русском и 48 из 64 на казахском,
против 5 из 8 и 43 из 58 у текущего механизма фраз. Он не вошёл в
пакет из-за снижения доли точных русских фраз.

### Собственная модель на частях слов

Экспериментальный GRU-предиктор учится по языковой метке и префиксу
предложения продолжать текст токен за токеном. Общий токенизатор BPE
позволяет собрать словоформу из подслов. При ранжировании модель выбирает
первое слово, затем оценивает вероятность добавить второе и третье.
Перед показом проверяется вероятность границы последнего слова.

Обучение и стенд используют Python, PyTorch и Tokenizers. Стенд сравнивает
кандидата со всеми тремя пакетами TilType. Экспериментальные веса хранятся
отдельно от установочных пакетов.

```powershell
$work = '.cache/tiltype-ai-variants/subword-phrase-model'
python tiltype-ai/tools/train_subword.py .cache/dialogue-corpora "$work/models" --epochs 1
python tiltype-ai/tools/benchmark_subword.py "$work/models" "$work/development.json"
```

Первый проход обработал 5 548 013 подсловных позиций. На выборке для
подбора из 200 позиций на язык он дал 20 совпадений первого слова на
русском, 13 на казахском и 25 на английском. У текущего Phrases на тех
же примерах — 35, 20 и 38, у словаря — 39, 30 и 57. Совпадение всей
фразы — 4 из 153 показанных у новой модели и 3 из 6 у Phrases.

После четырёх проходов модель дала 24, 12 и 29 совпадений первого
слова и 3 целые фразы из 174 показанных. На тех же входах p95
прототипа на CPU с PyTorch — 30,68 мс против 1,10 мс у Phrases и
0,019 мс у словаря. RSS после прогрева — 216, 69 и 310 МБ соответственно.
Установочный пакет продолжает использовать прежний движок.
